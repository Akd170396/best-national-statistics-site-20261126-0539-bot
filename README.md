NusaData — Statistik Nusantara: situs statistik nasional Indonesia yang berjalan sepenuhnya luring dari berkas statis. Beranda menampilkan kartu angka utama 2024 (penduduk 281,6 juta jiwa, pertumbuhan PDB 5,03%, inflasi 1,57%, kemiskinan 8,57%, pengangguran 4,76%, IPM 75,02) beserta grafik tren 2019–2024 yang bisa diganti metrik dan rentang tahunnya. Halaman Penduduk, Ekonomi, Pendidikan, Kesehatan, dan Ketenagakerjaan masing-masing punya kartu KPI, grafik tren, dan penjelasan; halaman Data & Metodologi memuat tabel provinsi yang bisa dicari dan diurutkan serta daftar lengkap sumber setiap angka (BPS dan SSGI Kemenkes). Semua grafik digambar sendiri di atas canvas tanpa pustaka, dan situs ini tidak memuat apa pun dari jaringan.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 di peramban desktop atau ponsel.
